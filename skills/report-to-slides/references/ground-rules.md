# Ground rules

These apply to every step of report-to-slides.

- **Faithful.** Every word, number and illustration on a slide comes from the report. Condense wording; add nothing: no new facts, numbers, examples, analogies, claims or diagrams. Keep the report's language exactly as it is.
- **Visual-first.** One idea per frame. The report's own illustrations (TikZ figures, images, tables) carry the frame. Using every figure is not required. A short equation (≤ 2 lines) or code (≤ 12 lines) appears only when it is the point. Everything else becomes bullets: ≤ 4 per list, one line each.
- **Guideline-styled.** The guideline is the only source of styling, and its frames are a layout catalog. See [layouts.md](layouts.md).
- **Complete.** Every report `\section` and `\subsection` ends up as a kept frame or a crossed-out skipped frame. No topic vanishes silently.
